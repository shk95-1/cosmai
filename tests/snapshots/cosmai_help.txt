$ cosmai --help
usage: cosmai [-h] {collect,analyze,retrieval,eval,lexicon} ...

positional arguments:
  {collect,analyze,retrieval,eval,lexicon}
    collect             Run one collector's dataset for one hour.
    analyze             Run one analysis stage over the needs schema.
    retrieval           Build the search corpus and query it.
    eval                Score one task against needs.labeled_set.
    lexicon             Load, compare and activate a dictionary version.

options:
  -h, --help            show this help message and exit

$ cosmai lexicon --help
usage: cosmai lexicon [-h] {load,diff,activate} ...

positional arguments:
  {load,diff,activate}
    load                Load one CSV as version n; a version already loaded is a no-op.
    diff                Show what version n adds, drops and rewrites against another version.
    activate            Make version n the active one and deactivate the rest of that kind.

options:
  -h, --help            show this help message and exit

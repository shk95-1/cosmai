$ cosmai --help
usage: cosmai [-h] {collect,login,analyze,retrieval,trend,eval,lexicon} ...

positional arguments:
  {collect,login,analyze,retrieval,trend,eval,lexicon}
    collect             Run one collector's dataset for one hour.
    login               Open a visible browser so a person can authorise one source's profile.
    analyze             Run one analysis stage over the needs schema.
    retrieval           Build the search corpus and query it.
    trend               Build the panel's quarterly topic series.
    eval                Score one task against needs.labeled_set.
    lexicon             Load, compare and activate a dictionary version.

options:
  -h, --help            show this help message and exit

# Objects that exist in production app.needs but are not created by this checkout's
# contracts/ddl/needs/*.sql. When the fork puts DDL into production it sends one line here as a PR --
# someone else's DDL entering production gets declared.
#
# Why this file and not the ledger (needs.schema_migration) is the reference: the ledger may hold 020,
# but that file is not in this checkout, so the expectation cannot be assembled. DDL someone else
# applied is declared, not assembled.
#
# Only tool/checks/ddl-drift reads it. One object per line, everything after '#' is a comment:
#   <table>           the whole table. Dropped from the production pg_dump by -T needs.<table>.
#   <table>.<column>  one column. pg_dump has no column exclusion, so the production dump is restored
#                     into a throwaway postgres, the column is DROPped and it is dumped again.
#
# If production holds someone else's object that is not listed here, ddl-drift fails as DRIFTED --
# that is what this file is worth. Conversely a table this repo declares must not be excluded: the
# moment it is, that table's drift is invisible forever.
#
# But "this repo" is not one repo. The very reason this file exists is that another repo exists, and
# merged into that repo the same nine lines mean the opposite -- the upstream cosmai checkout has no
# 020~025, so all nine are someone else's, while the fork cosmai-import-ydc checkout has 020~025 and
# their views, so all nine are its own declarations (cosmai#108). So the verdict is asked of the
# **checkout** rather than of this list: objects this checkout declares are ignored -- listed or not,
# they are not excluded and are compared against the expectation as they are. The rule lives in one
# place, tool/ddl-foreign-entries, and so does the reason ignoring does not weaken the check: an
# ignored object stands in the expectation and stays in the production dump, so it is still compared.
# Declare it on both sides and both sides are seen. In upstream none of the nine is declared, so this
# rule touches not one line.
